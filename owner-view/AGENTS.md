# PAIGE Cloud console UI and UX

For every console UI or UX change, select and apply the skill that fits the work.

- [Game UI/UX](https://www.skills.sh/gamedev-skills/awesome-gamedev-agent-skills/game-ui-ux) for screen hierarchy, layout, keyboard focus, and navigation.
- [Level Design](https://www.skills.sh/gamedev-skills/awesome-gamedev-agent-skills/level-design) for journeys, landmarks, and clear return paths.
- [Animate](https://www.skills.sh/emilkowalski/skills/animate) for timing, interaction feedback, and reduced motion.

Follow the existing PAIGE evidence and review process. Record the chosen skill with the rendered checks. See the [Linear directive](https://linear.app/paigeagentai/issue/ANT-147#comment-6ca6ba0d-6c3a-45a5-a8e9-41eccc790cd7).
